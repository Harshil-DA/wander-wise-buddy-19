**WanderBuddy**

**WanderBuddy** is a travel-focused web application built to make discovering and planning trips easier through a simple, interactive interface.

The project combines a modern frontend with backend services to create a foundation for a personalized travel-planning experience.

**Features**

* Explore and discover travel destinations
* Organize and plan travel experiences
* Location-focused travel information
* Responsive and interactive user interface
* Backend integration using Supabase
* Fast development setup using Vite and TypeScript

**Tech Stack**

* **TypeScript**
* **Vite**
* **React**
* **Supabase**
* **Git & GitHub**

**Purpose**

This project was built to explore how modern web technologies can be used to create a more convenient and engaging travel-planning platform.

It also served as a hands-on project for understanding **frontend development, backend integration, application structure, and modern development workflows**.

**Future Scope**

Some areas that can be expanded in future versions include:

* AI-powered itinerary generation
* Personalized destination recommendations
* Budget and expense tracking
* Maps and route planning
* Weather and travel information
* Hotel and activity recommendations
